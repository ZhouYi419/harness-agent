## 模板使用规则

- 文档状态默认是“草稿”；存在待确认事项时使用“待确认”；只有用户明确确认整份 PRD 后才使用“已确认”。
- 成功指标、优先级、性能阈值或 SLA 未经用户确认时，不得自行填写具体数字。
- 非功能要求只记录与当前 MVP 有关且已确认的性能、安全、隐私、兼容性、可用性或可观测性要求。
- 没有 Agent 建议时写“无”；建议不得出现在范围内、功能需求或验收标准中。
- 创建后保持 ID 稳定。修订时保留未受影响的 ID；新增项目使用当前同类最大序号之后的新 ID，删除后的 ID 不复用。
- 本模板仅是 JSON 的人类可读投影；不得直接修改投影后宣称结构化事实源已经同步。
